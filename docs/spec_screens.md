## 2. 레이아웃 (W0 · 앱 셸)

- 화면 1920 기준. **상단 내비게이션** 높이 70(하단 1px `divider`), **좌측 내비게이션** 너비 118(오른쪽 1px `divider`), 나머지는 콘텐츠 영역.

- 상단 왼쪽: [Groups] 테스트 · [SpaceDashboard] 오버뷰 [ExpandMore] / 오른쪽: [HelpOutline] 지원 · [Update] 업데이트 · [Language] 한국어 · [Search] 빠른 검색 `⌘` `K` · 구분선 · [Person] seong.cheol (모두 16 Medium, 아이콘 20, 항목 간격 32)
- 좌측: 로고(48×48 검정 둥근 사각형, 흰 "A") 아래 메뉴 버튼 48×48 7개(간격 9): 4각 별(AI) · Link · BarChart · ManageHistory · 데이터베이스(원통) · **Tune(현재: 기여 규칙, `primary-weak` 배경 · `primary` 아이콘)** · Settings
- **기여 규칙 외 모든 내비게이션 항목**을 누르면 이동하지 않고 "준비되지 않은 화면" 안내 팝업(7-5).

- 아이콘: `@mui/icons-material` 이름을 그대로 쓴다. 4각 별과 데이터베이스(원통)는 기본 세트에 없어 SVG로 직접 그린다(선 굵기 2, 24 viewBox).

## 3. 공통 컴포넌트

### 3-1. 값 입력 (값 칸 + 단위 칸)
- 값 칸: 110×38, 흰 배경, `border`, 모서리 6, 왼쪽 숫자(14), 오른쪽 아래 화살표(열리면 위 화살표).
- 단위 칸: 90×38, `bg-muted`, 테두리 없음, 모서리 6, "일 · 시간 · 분 · 년" + 아래 화살표.
- 두 칸 간격 8.
- 상태: 일반(숫자 `text-primary`) / **위 값 따르기**(숫자 `text-placeholder`, 단위 칸은 일반 색 그대로) / **비활성**(광고 채널 정책 칸: 회색 배경, 수정 불가).

### 3-2. 값 드롭다운
- 너비 216~240, 흰 배경, `border`, 모서리 8, 그림자.
- 맨 위 입력칸: 돋보기 + 플레이스홀더 "0 ~ 최대값" + 오른쪽 스텝퍼(▲▼). 직접 입력 가능. 포커스 테두리 2px `primary`.
- (채널 · 캠페인 행만) **"○○ 값 따르기"** + 아래 캡션 "현재 N일"(11, `text-placeholder`), 그 아래 구분선. 채널 행은 "글로벌 값 따르기", 캠페인 행은 "{채널명} 값 따르기". 글로벌 행 · 인앱 이벤트 행에는 없음.
- "All Values"(13, `text-secondary`) 아래 프리셋 목록(14). 현재 값은 `primary` 글자. 맨 아래 "0 (기여하지 않음)".
- 범위 밖 입력: 목록 대신 빨간 테두리 + "0~{최대} 사이의 값을 입력해 주세요"(12, `text-danger`).
- 단위별 범위 · 프리셋:

| 탭 | 단위 | 범위 | All Values |
| --- | --- | --- | --- |
| 설치(룩백) | 일 | 0 ~ 30 | 1 · 7 · 14 · 30 · 0 |
| 설치(룩백) | 시간 | 0 ~ 24 | 1 · 6 · 12 · 24 · 0 |
| 설치(룩백) | 분 | 0 ~ 60 | 1 · 5 · 15 · 30 · 60 · 0 |
| 인앱이벤트(어트리뷰션) | 년 | 0 ~ 2 | 1 · 2 · 0 |
| 인앱이벤트(어트리뷰션) | 일 | 0 ~ 730 | 1 · 7 · 14 · 30 · 60 · 90 · 180 · 365 · 730 · 0 |
| 인앱이벤트(어트리뷰션) | 시간 | 0 ~ 24 | 1 · 6 · 12 · 24 · 0 |
| 인앱이벤트(어트리뷰션) | 분 | 0 ~ 60 | 1 · 5 · 15 · 30 · 60 · 0 |

> 0은 화면에 "기여하지 않음"으로 표시한다(조회 화면 표 · 툴팁 모두).

### 3-3. 버튼
| 종류 | 모양 | 예 |
| --- | --- | --- |

| outline | 흰 배경, `primary` 테두리 · 글자, 모서리 8 | ✎ 수정, + 추가, + 인앱 이벤트 추가, ⚙ 기간 설정 |

| danger | `danger` 배경, 흰 글자 | 삭제 |
| disabled | `divider` 배경, `text-placeholder` 글자 | 비활성 저장 · 적용 |
| text-link | 글자만 `primary` 12~13 Medium | + 캠페인 한정 설정 추가 |

## 4. 설치 탭 (W1 조회 · W2 수정)

### 4-1. 조회 화면 구성 (위에서부터)
1. "기여 규칙"(page-title) + ? 아이콘
2. 상위 탭: **설치** | 인앱이벤트 (선택 탭 밑줄 3px `text-primary`, 탭 좌우 여백 12, 아래 전체 너비 1px 디바이더)
3. 설명 문구(14): "설치 이벤트에 대한 룩백 윈도우를 터치포인트 종류와 유저 식별 방법에 따라 설정할 수 있습니다. 룩백 윈도우는 채널에서 발생한 클릭, 조회가 설치 이벤트와 관련 있다고 판단되는 기간입니다. 글로벌 외에 채널별로, 채널 안에서는 캠페인별로 다르게 설정할 수 있으며, 따로 설정하지 않은 값은 캠페인 → 채널 → 글로벌 순으로 위 단계 값을 따릅니다." + "⊕ 가이드 보러가기"
4. 섹션 헤더: "룩백 윈도우" ⓘ + "아래 차트는 유저 식별 방법 중에 [디바이스 ID 매칭]을 기준으로 표시됩니다." / 오른쪽 [✎ 수정]
5. 기간 차트(4-2)
6. 도구 막대(오른쪽 정렬): ☐ 종료된 캠페인 포함 · [캠페인 검색] 입력칸(280×36)
7. 목록 표(4-3)
8. 하단 설정 카드 2개(4-6)

### 4-2. 기간 차트 (룩백)
- 가로축: 왼쪽 "터치포인트" … 오른쪽 "⤓ 설치". 막대는 설치 지점에서 왼쪽으로 뻗음.
- 디바이스 ID 매칭 두 칸만 그림: 클릭 = 높은 연한 막대(`chart-lookback-light`), 조회 = 낮은 진한 막대(`chart-lookback-strong`). 막대 끝 아래 라벨 "클릭(N일)", "조회(N일)".
- **막대 길이(운영 중인 대시보드와 같음)**: 화면에 그리는 값(클릭 · 조회 · 비교 점선) 중 가장 긴 값 = 전체 길이. 막대 길이 = 전체 × (0.13 + 0.87 × 값 / 가장 긴 값). 짧은 값과 0도 최소 13%로 보인다. 막대 왼쪽 끝 아래에 ▼ 표시.
- **값 0**: 최소 길이 막대 + "클릭(0일)" · "조회(0일)" 라벨. (차트 막대 라벨만 0을 숫자로 쓴다. 표 · 툴팁은 "기여하지 않음")
- **클릭 · 조회 값이 같으면** 라벨 하나로 "클릭, 조회(30일)".
- 선택한 행 기준. 진입 시 글로벌 선택.
- 비교 점선: 채널 선택 시 글로벌 값, 캠페인 선택 시 속한 채널 값을 클릭 · 조회 각각 점선 + "이름: 클릭(N일)" · "이름: 조회(N일)" 라벨로 겹침. 위 단계 값이 0이어도 최소 길이 위치에 점선("이름: 조회(0일)"), 두 값이 같으면 "이름: 클릭, 조회(N일)" 하나로.
- 호버: 세로선 + 클릭 막대 윗변의 점 + 툴팁. 툴팁 = 선택한 행 이름(캠페인이면 위에 채널명 캡션) / 4칸(클릭 · 조회 × 디바이스 ID 매칭 · 확률적 모델링) 각각 "어트리뷰션 대상"(`primary`) 또는 "어트리뷰션 대상 제외"(`text-danger`). 마우스 지점의 설치 전 기간이 그 칸 값 이내면 대상.

### 4-3. 목록 표
- 열: 채널 / 캠페인(700) · 클릭 디바이스 ID 매칭 · 클릭 확률적 모델링 · 조회 디바이스 ID 매칭 · 조회 확률적 모델링 · 최근 수정일. 헤더는 두 줄("클릭" / "디바이스 ID 매칭"), 12 `text-secondary`, `bg-subtle`.
- 행: **글로벌**(ⓘ) + **추가한 채널**만. 채널은 개수 제한 · 접기 없이 모두.
- 선택된 행: 왼쪽 3px `primary` 바 + 글자 Bold. 나머지 행 글자 `text-secondary`.
- 채널 행 이름 칸: 1줄 채널명 + ⓘ(광고 채널 정책이 있는 채널만), 2줄 [캠페인 한정 설정 N개 ⌄](캠페인 설정이 있을 때만). N = 사용자가 설정한 캠페인 수(정책 캠페인 제외), "종료된 캠페인 포함" 체크 여부에 따라 보이는 수 기준.
- 캠페인 행: 채널 아래, 앞에 회색 └ 연결선. **채널 값과 같은(위 값을 따르는) 칸은 흐린 칸**(`bg-muted` 배경 + `text-placeholder`), 직접 설정한 칸은 흰 칸. 종료된 캠페인은 이름 옆 "종료됨" 태그.
- 값 0은 "기여하지 않음".
- 최근 수정일 "YYYY-MM-DD ↗".
- 행을 누르면 선택 → 차트 전환. 펼치기 버튼은 펼치기만(선택과 별개).

### 4-4. ⓘ 툴팁 문구

### 4-5. 캠페인 검색 (조회)
- 대상: 목록에 있는(캠페인 한정 설정이 있는) 캠페인. 기본은 진행 중만, 체크하면 종료 포함.
- 입력 즉시 검색창 아래 드롭다운: 머리말 "진행 중인 캠페인" 아래 캠페인명(일치 부분 Bold) + 채널명 캡션. 종료 포함 시 구분선 아래 머리말 "종료된 캠페인" + "종료됨" 태그.
- 결과 선택: 속한 채널 펼침 → 그 캠페인 선택(차트 전환) → 자동 스크롤 → **이름 칸만** `primary-weak` 2초 하이라이트 후 원래대로(선택 표시는 유지). 목록은 필터링하지 않음. 검색창에는 고른 캠페인명이 남고 ✕로 지움.
- 결과 없음(체크 안 함): "진행 중인 캠페인 중 "{검색어}"과 일치하는 결과가 없어요." + (회색) "종료된 캠페인도 찾으려면 '종료된 캠페인 포함'을 체크하세요. 캠페인 한정 설정이 없는 캠페인은 속한 채널 값을 따릅니다."
- 결과 없음(체크함): ""{검색어}"과 일치하는 결과가 없어요." + (회색) "캠페인 한정 설정이 없는 캠페인은 속한 채널 값을 따릅니다."
- 조사 "과/와"는 검색어 끝 글자 받침에 맞춘다.

### 4-7. 수정 모드 (W2)

### 5-1. 조회 화면 구성

2. 설명 문구(기존 그대로): "타겟 이벤트인 설치, 딥링크 실행, 딥링크 페이지뷰에 대한 어트리뷰션 윈도우를 설정할 수 있습니다. 어트리뷰션 윈도우는 타겟 이벤트 후에 발생한 전환인 인앱이벤트가 타겟 이벤트와 관련 있다고 판단되는 기간입니다. 이때 어떤 인앱이벤트가 여러 타겟 이벤트의 어트리뷰션 윈도우에 있으면 가장 최근에 발생한 타겟 이벤트에 기여한 채널의 성과로 측정됩니다." + "⊕ 가이드 보러가기"
3. 하위 탭: **설치** | 딥링크 실행 | 딥링크 페이지뷰 (선택: `primary` 글자 + 2px 밑줄, 아래 디바이더). 딥링크 두 탭은 안내 팝업(7-5).
4. 헤더: "설치에 대한 어트리뷰션 윈도우" ⓘ(툴팁: "이 기간에 있는 인앱이벤트는 설치 이벤트에 기여한 채널의 성과가 됩니다.") / 오른쪽 [✎ 수정]
5. **인앱 이벤트 레이어**(5-2)
6. 기간 차트(5-3)
7. 도구 막대(설치 탭과 같음)
8. 목록 표: 열 채널 / 캠페인 · 설치 · 최근 수정일. 규칙은 설치 탭과 같음. 단 값이 한 칸이라 캠페인 행은 항상 자기 값(흐린 칸 없음). 광고 채널 정책 ⓘ 없음.

### 5-2. 인앱 이벤트 레이어
- `bg-subtle` 배경, 모서리 8, 안쪽 여백 16/16/16/20.
- 1줄: "인앱 이벤트별 기간 설정 **N개**"(15 Bold, N은 `primary`) + 같은 줄 안내(13 `text-secondary`): "설정한 인앱 이벤트는 캠페인 · 채널 · 글로벌보다 우선합니다. 설정하지 않은 인앱 이벤트는 캠페인 → 채널 → 글로벌 순으로 따릅니다." (잘려도 됨)
- 2줄: **인앱 이벤트 필터**(너비 고정 360, 높이 38) + [⚙ 기간 설정](outline)
  - 기본: "선택하지 않음"(`text-placeholder`)
  - 이벤트 선택 시: "{이벤트명} {기간}"(기간은 `primary`, 0이면 "기여하지 않음" `text-placeholder`)
  - 드롭다운(너비 360): 맨 위 검색 "인앱 이벤트 검색" → "선택하지 않음 — 채널 · 캠페인 기간 기준"(오른쪽 회색) → 구분선 → "기간을 설정한 인앱 이벤트 N개 · 최근 등록순" → 이벤트명(커스텀이면 "커스텀" 태그) + 오른쪽 기간. 목록만 스크롤(높이 약 260).
  - 0개일 때: "선택하지 않음" + "기간을 설정한 인앱 이벤트가 없습니다."
- 다른 행을 선택해도 필터는 유지.

### 5-3. 기간 차트 (어트리뷰션)
- 가로축: 왼쪽 "설치 ⤓" … 오른쪽 "측정 대상 제외". 막대는 설치 지점에서 오른쪽으로 뻗음.
- **필터 "선택하지 않음" (기존과 동일)**: 막대 하나(`chart-attr-light`, 선 `#338059`, 끝에 ▼ 화살표). 기준선(위 단계 값: 채널 선택 시 글로벌, 캠페인 선택 시 채널)은 **오른쪽 고정** 점선 + "{이름}({기간})" 라벨. 선택한 값이 기준보다 **짧으면 비율만큼, 같거나 길면 기준선 앞까지 꽉 채움**. 글로벌 선택 시 기준선 없이 꽉 채움. 막대 끝 아래 "인앱이벤트({기간})".
- **필터로 인앱 이벤트를 고름**: 막대 두 개를 겹침(설치 탭 클릭 · 조회 방식). 그 외 인앱 이벤트(선택한 행의 값, 연한 초록) + 고른 인앱 이벤트(이벤트 설정 값, 진한 초록 `chart-attr-strong`). **긴 쪽이 높은 막대로 꽉 차고(뒤), 짧은 쪽은 낮은 막대로 비율만큼(앞)**. 각 막대 끝 아래 "그 외 인앱 이벤트(7일)", "구독 시작(60일)"(모두 `text-primary` 12 Regular). 위 단계 점선 없음. 두 값이 같으면 같은 길이로 겹치고 라벨은 "그 외 인앱 이벤트 · 구독 시작(60일)" 하나로.
- **고른 이벤트 값이 0**: 그 이벤트 막대는 그리지 않고 설치 지점 옆에 "{이벤트명}(기여하지 않음)" 라벨만.
- 비율 계산: 짧은 값 / 긴 값 = r 일 때 막대 길이 = 전체 × r^0.7 (짧은 기간도 보이도록).
- **호버 툴팁**: 제목 = 선택한 행 이름(캠페인이면 채널명 캡션). 본문 "예상되는 어트리뷰션 결과" 아래
  - 막대 하나: 기간 안이면 "인앱이벤트는 설치 이벤트에 기여한 채널의 성과가 됩니다."(`primary`), 밖이면 "인앱이벤트는 채널의 성과가 되지 않습니다."(`text-placeholder`)
  - 막대 두 개: 두 줄 — "그 외 인앱 이벤트 (7일)" + 결과 문장 / "구독 시작 (60일)" + 결과 문장. 0인 이벤트 줄은 항상 "성과가 되지 않습니다".

### 5-4. 인앱 이벤트 기간 설정 팝업 ([⚙ 기간 설정])
- 적용 확인 팝업과 같은 틀(너비 760, 모서리 20).
- 제목 "인앱 이벤트별 기간 설정 **N개**" + ✕ / 안내 "설정한 인앱 이벤트는 캠페인 · 채널 · 글로벌보다 우선합니다. 설치 타겟 이벤트의 어트리뷰션 윈도우에 적용됩니다."
- 표: 인앱 이벤트(이벤트명 + 커스텀 태그) · 설치(값 입력, 인앱이벤트 단위) · 쓰레기통. 최근 등록순. 팝업 높이는 고정하고 목록만 스크롤.
- [+ 인앱 이벤트 추가] → 표 맨 아래 새 행: 선택창 "인앱 이벤트를 선택해 주세요." + 드롭다운(검색 "인앱 이벤트를 선택하거나 검색해 주세요.", 그룹 "스탠다드 이벤트" / "커스텀 이벤트", 아직 기간을 설정하지 않은 이벤트만, 검색은 두 그룹 함께). 값은 고르기 전 · 후 **0 · 일**.
- [취소] [저장]. 저장 비활성: 바뀐 내용 없음 / 이벤트를 고르지 않은 빈 행.
- 저장 → 적용 확인 팝업: 안내 박스 **"인앱 이벤트 설정은 모든 채널 · 캠페인의 기여 기간보다 우선 적용됩니다."** 한 줄. 취소 / ✕ → 기간 설정 팝업으로 돌아감(입력 유지). 적용 → 두 팝업 닫히고 레이어 개수 · 필터 목록 갱신.
- 바꾼 내용이 있는 채 취소 / ✕ → 나가기 팝업(기간 설정 팝업 위). 취소 = 돌아가기, 떠나기 = 버리고 모두 닫기.
- 쓰레기통 → "{이벤트명}의 기여 기간을 삭제하겠습니까?" / "기여 기간을 삭제하면 이 인앱 이벤트에는 캠페인 · 채널 · 글로벌 순으로 설정된 기여 기간이 적용됩니다." / [취소] [삭제]

### 5-5. 수정 모드
- 채널 · 캠페인 표만 입력 상태(설치 탭과 같은 규칙, 값 한 칸, 인앱이벤트 단위 드롭다운).
- **인앱 이벤트 레이어와 차트 모두 `overlay` Dim**(필터 · [기간 설정] 조작 불가). 차트엔 "수정 중".
- [+ 추가] 채널은 **0 · 년**으로 시작(기존 동작).
- 캠페인 추가는 고른 순간 "{채널명} 값 따르기", 값을 바꾸기 전까지 저장 비활성.

## 6. 상태 · 동작 공통 규칙
- 진입 시 각 탭 글로벌 선택, 캠페인은 모두 접힘.
- 종료된 캠페인: 조회 기본 목록 · 검색에서 숨김, 체크 시 "종료됨" 태그와 함께. 수정 모드에서는 항상 숨김.
- 하이라이트: 이름 칸만 `primary-weak` 2초.
- 저장은 탭(그리고 인앱 이벤트 팝업) 단위. 저장해도 지난 데이터는 다시 계산하지 않음(목업이므로 화면 상태만 갱신, 최근 수정일은 오늘로).
- 설치 탭과 인앱이벤트 탭의 데이터는 서로 독립.
